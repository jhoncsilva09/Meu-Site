Landing page - Perfil profissional

Este repositório contém uma landing page simples e responsiva para um perfil profissional (Jônatas).

Arquivos principais:
- index.html — estrutura do site (seções: início, história, carreira, índice de aprovação, depoimentos, contato)
- style.css — estilos modernos e responsivos
- script.js — interatividade mínima: menu mobile, animação das barras de aprovação e slider de depoimentos

Como personalizar
1. Substitua `profile-placeholder.png` por sua foto (mesmo nome ou atualize o `src` em `index.html`).
2. Atualize textos das seções (`Minha História`, `Minha Carreira`, etc.) diretamente em `index.html`.
3. Atualize links de contato no bloco `#contato` (email, LinkedIn, WhatsApp).

Como testar localmente
- Abra `index.html` no navegador (duplo clique ou arraste para o navegador).
